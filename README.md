# A/B Testing-Analysis
  Для проведения A/B-тестирования использовался открытый датасет, размещённый на платформе Kaggle. Датасет представляет собой смоделированные пользовательские данные, агрегированные на уровне отдельных пользователей, и предназначен для анализа веб-экспериментов, связанных с пользовательским взаимодействием с интерфейсом.

  Данные представлены в виде таблицы с пользовательской агрегацией. Каждая строка соответствует одному уникальному пользователю, участвующему в эксперименте. Общий объём выборки составляет 120 000 наблюдений, что обеспечивает достаточную статистическую надёжность при проведении анализа.
Датасет включает следующие переменные:

    user_id - уникальный идентификатор пользователя;
    group - принадлежность пользователя к группе (контрольной или тестовой);
    views - количество просмотров веб-страницы пользователем;
    clicks - количество кликов по экспериментальной кнопке.
    
  Таким образом, данные имеют плоскую структуру, не содержат временной компоненты и предназначены для сравнения агрегированных пользовательских метрик между двумя независимыми группами.

  Очистка и подготовка данных.
  Первичный просмотр таблицы показал, что каждая строка соответствует одному уникальному пользователю и содержит информацию о принадлежности к экспериментальной группе, количестве просмотров страницы и числе кликов.
  Анализ общей информации о датасете показал, что:
  
    -	общее число наблюдений составляет 120 000;
    -	все переменные имеют корректные типы данных;
    - пропущенные значения отсутствуют во всех столбцах;
    - размер контрольной и тестовой групп одинаков и составляет по 60 000 пользователей.
  Таким образом, датасет не требует дополнительной очистки от пропусков или дублирующихся записей, а равномерное распределение пользователей между группами свидетельствует о корректно проведённой рандомизации.

  Для оценки наличия аномальных наблюдений были проанализированы описательные статистики количественных переменных views и clicks. Полученные результаты показывают, что медианные значения существенно ниже средних, а максимальные значения значительно превосходят верхние квартили.
  В частности:
  
    •	медианное число просмотров равно 3, тогда как максимальное значение достигает 205;
    •	для кликов медиана равна 0, при максимальном значении 9.
  Подобные характеристики указывают на выраженную асимметрию распределений и наличие редких пользователей с аномально высокой активностью. При этом данные значения не являются результатом ошибок измерения и отражают допустимое пользовательское поведение, характерное для веб-экспериментов. В связи с этим выбросы не были удалены из выборки, однако их наличие было учтено при выборе статистических методов анализа.

  Сформулируем бизнес-гипотезы:
  
  Нулевая гипотеза (H0): внедряемое изменение не оказывает влияния на вовлечённость пользователей, измеряемую количеством просмотров и кликов; поведение пользователей в тестовой группе не отличается от поведения пользователей в контрольной группе.
  
  Альтернативная гипотеза (H1): внедряемое изменение влияет на вовлечённость пользователей и приводит к изменению количества просмотров и/или кликов по сравнению с контрольной группой.

  Статистические гипотезы. 
  
  H0: нет разницы в просмотрах/кликах между группами.
  
  H1: между контрольной и тестовой группами существует статистически значимая разница в значениях метрики.

В рамках данного эксперимента также рассматривается односторонняя формулировка гипотез, отражающая ожидание улучшения метрик в тестовой группе.
H0: значения метрик (просмотры / клики) в тестовой группе не превышают соответствующие значения в контрольной группе.
H1: значения метрик в тестовой группе выше, чем в контрольной группе.
